351WatchBot

351WatchBot is the crawler behind 351 Watch. It reads the meeting agendas, warrants and notices that towns and counties post on their own websites, and flags items about solar, battery storage, data centers, moratoria, zoning changes and similar land-use decisions.

How it identifies itself

Every request carries this User-Agent:

351WatchBot/0.1 (+https://351watch.vercel.app/bot)

Requests are also signed with Web Bot Auth (HTTP Message Signatures, Ed25519). The public key is at /.well-known/http-message-signatures-directory, and each request names that directory in a Signature-Agent header.

What it does and doesn't do

  • Checks robots.txt before every request, including each redirect, and skips anything disallowed for 351WatchBot or *.
  • Makes at most one request per second to a host, or waits longer if robots.txt sets a Crawl-delay.
  • Reads each meeting listing about once a day and downloads each agenda document once.
  • Reads only public pages. It never logs in, never submits forms and never tries to get past a CAPTCHA or other bot check.
  • Skips files larger than 40 MB.

Blocking it or slowing it down

To stop it, add this to your robots.txt. It takes effect on the next visit.

User-agent: 351WatchBot
Disallow: /

To slow it down, add a Crawl-delay line giving the number of seconds to wait between requests. If you run a town or county website and want a different arrangement, or think the crawler misbehaved, send us a note with your site's address.

351 Watch compiles public records: agendas and warrants that towns post under state open meeting laws, Attorney General decision letters, court rulings and legislative records. It is informational only and is not legal advice. Confirm dates and terms with the town clerk or the linked source before relying on them.
