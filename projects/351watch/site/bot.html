For website managers

AgendaAheadBot visits town websites once a day, reads only public agenda pages and follows each website’s robots.txt rules.

If you run a town website and want it to stay away, add this to your robots.txt:

User-agent: AgendaAheadBot
Disallow: /

It identifies itself on every visit as:

AgendaAheadBot/0.1 (+https://agendaahead.vercel.app/bot)

Visits are signed with Web Bot Auth. The public key is at /.well-known/http-message-signatures-directory.

  • It checks robots.txt before every visit, including redirects.
  • It asks a website for at most one page a second, or less often if the website says so.
  • It opens each agenda page about once a day and each agenda once.
  • It never logs in, fills in forms or gets past a bot check.
  • It skips files larger than 40 MB.

Want something different? Send us a note.
